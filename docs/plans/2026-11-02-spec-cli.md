# Rename `ac-run` to `spec` (Pi handoff)

## Context

The human finds `ac-run` hard to remember. The spec-loop CLI becomes `spec <verb>`:
`spec lint`, `spec approve`, `spec show`, `spec check`, `spec reject`, `spec status`.
`scripts/ac-run` stays as a silent compatibility shim so running Pi tasks, old plans and
archived specs keep working. The behaviour of every subcommand is unchanged.

## Rules for this run

- Work only inside this worktree (branch `chore/spec-cli`). Do not create worktrees or branches.
- Commit each coherent unit through the funnel only:
  `$HOME/dotfiles/scripts/commit-funnel --worktree "$PWD" -F <message file> <path>...`
  Write message files under `$TMPDIR`. Do not push.
- Never run `approve` or `reject` (old or new name). Never weaken a test to make it pass;
  updating a test's expected command name from `ac-run` to `spec` is the intended change.
- Do not edit archived documents: anything under `docs/specs/`, `docs/plans/` (except this
  file), `docs/superpowers/`, `specs/`, and `docs/SPEC-commit-funnel.md` keep the old name.
